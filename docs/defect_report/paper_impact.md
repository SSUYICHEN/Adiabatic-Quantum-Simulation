# 缺陷 A 對已發表論文圖表的實際影響

日期：2026-09-16。對應 `defects_before_after.ipynb` 第 2 節（缺陷 A：Givens 反號）。
數據：`paper_impact.json`（由 `paper_impact_recompute.py` 以 CUDA-Q `nvidia-fp64` 產生，
N=6、T=1、L=40，與論文 Sec. V 相同），圖：`figures/paper_*.svg`（`paper_impact_plot.py`）。

## 1. 一句話結論

**缺陷 A 的電路輸出，與「修正後程式、但 U_A、U_B 全部反號」的輸出逐位元相同。**
論文 Fig. 3、Fig. 4 中所有 ΔU ≠ 0 的曲線，畫的其實是 U_A = −0.01、ΔU → −ΔU（吸引型 Hubbard 不平衡）
的結果，卻標成排斥型。ΔU = 0 的曲線與 Fig. 2 不受影響。

## 2. 為什麼是「精確等價」而不是「大約差一點」

子格點變換 C：b_{js} → −b_{js}（所有 j、s）是佔據基底上的對角相位 (−1)^{Σ n_B}。

- 它把每一個躍遷項 v a†b、w b†a 的符號反過來：H_hop → −H_hop（PBC、OBC 皆然）。
- Hubbard 項 n_↑ n_↓ 只含密度，完全不變。
- 因此 C · H(v, w, U_A, U_B) · C† = −H(v, w, −U_A, −U_B)。

舊碼把最低軌域的 Givens 角度反號，製備出的是 H_0 在該扇區的**最高**本徵態，
也就是 C|GS(H_0)⟩。接著每一步 Trotter 閘在 C 下逐一對應到「U 反號、時間反向」的閘，
所以整條電路（含 Trotter 誤差）都恆等於修正後程式在 (−U_A, −U_B) 下的電路，
只差一個對角相位 C。C 不改變任何位元字串機率，而 Berry 相位與極化都只從位元字串機率算出。

數值驗證（N=3，qiskit 精確態向量）：
`max |p_legacy(U) − p_fixed(−U)|` 在四組參數（PBC/OBC、ΔU 0.3–3）皆 ≤ 3e-16；
N=6 論文參數下，Fig. 4 全部七個 ΔU 的極化剖面前後差 ≤ 7e-10（fp64 GPU 精度）。

## 3. 論文圖表逐一對照（N=6，論文參數重算）

### Fig. 2（Trotter 收斂）：不受影響

`fidelity_scan` 以製備態本身為參考。最高能帶的行列式態同樣是 H_0 的本徵態，
演化後只差整體相位，曲線與修正後版本差 4e-16。

### Fig. 3 上圖（γ 對 w，各 ΔU）：ΔU = 0 不變；ΔU ≠ 0 的偏離方向相反

| ΔU | w=1.5 修正前（論文） | w=1.5 修正後 | w=0.5 修正前 | w=0.5 修正後 |
|---|---|---|---|---|
| 0 | 0.0000 | 0.0000 | 1.0000 | 1.0000 |
| 0.01 | −0.0015 | +0.0015 | 0.9999 | 1.0001 |
| 0.1 | −0.0148 | +0.0146 | 0.9993 | 1.0007 |
| 0.3 | −0.0449 | +0.0435 | 0.9978 | 1.0021 |

「ΔU 增大時 γ 離開量子化值」的定性結論成立，量級也幾乎相同（小 ΔU 下偏離對 ΔU 是奇函數）；
但論文畫的是往下偏，正確物理是往上偏。

### Fig. 3 下圖（γ 對 ΔU，w = 2）：論文曲線 = 修正前

| ΔU | 修正前（論文） | 修正後 |
|---|---|---|
| 0.1 | −0.015 | +0.015 |
| 0.3 | −0.046 | +0.044 |
| 1 | −0.158 | +0.139 |
| 3 | −0.490 | +0.349 |

論文圖上 ΔU=1 約 −0.15、ΔU=3 約 −0.45 到 −0.49，與修正前的重算一致，確認論文使用的是有缺陷的版本。
ΔU ≥ 1 時兩者大小也不同（0.49 對 0.35），因為此時已超出線性響應。

### Fig. 4 上圖（極化剖面）：體內偏移符號相反，兩端邊緣角色互換

| ΔU | 修正前（論文）cell 1 … cell 6 | 修正後 |

| 2 | 0.721, −0.521, −0.532, −0.532, −0.543, −1.266 | 1.226, 0.477, 0.468, 0.468, 0.459, −0.744 |

物理檢查：ΔU = U_B − U_A > 0 代表 B 格點排斥較強，填充超過一半（14 電子）時電子應往 A 移動，
體內 ⟨n_A − n_B⟩ 應為**正**。論文圖中體內偏移為負，正是 U 反號的徵兆。

### Fig. 4 下圖（第一晶胞極化對 ΔU）：趨勢方向相反

論文：cell 1 極化從 1.0 隨 ΔU 下降到 0.73（ΔU=2）。
修正後：cell 1 極化從 1.0 **上升**到 1.23；下降到 0.74 的是 cell 6（B 邊緣）。
「ΔU ≲ 0.01 邊緣特徵保留、ΔU ≳ 0.5 開始明顯改變」的定性敘述仍成立，但「degrades」的描述與圖需要對調到 cell N。

## 4. 需不需要修正

需要。理由不是結論被推翻，而是**圖與文字描述的是與標示不同的哈密頓量**：

1. 圖中標示 U_A = 0.01、ΔU > 0（排斥），實際對應 U_A = −0.01、ΔU < 0（吸引）。
2. Fig. 4 體內偏移的符號、Fig. 3 偏離量子化值的方向，都與排斥型物理相反；審稿人或讀者用平均場直覺即可看出矛盾。
3. Sec. III-A 與 Eq. (15) 宣稱初態是基態並演化到目標基態，實際模擬追蹤的是扇區內最高本徵態。
   方法敘述本身是對的，是實作偏離了敘述；修正後程式才符合論文所述方法。

不需要修正的部分：Fig. 1（電路）、Fig. 2、Fig. 3 與 Fig. 4 中 ΔU = 0 的曲線、
所有解析推導（Sec. II–IV）、以及「弱不平衡下拓樸特徵穩健、強不平衡下破壞」的主要結論。

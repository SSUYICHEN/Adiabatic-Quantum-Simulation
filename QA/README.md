# Adiabatic-Quantum-Simulation

## Overview
Adiabatic Quantum computing is designed for optimization problems by solving system on gate-based quantum computer. This repository provides an implementation for computing topological properties of an interacting many-body quantum system whose correlated topological features become classically challenging to evaluate at scale.

## Author
This repository is maintained by Ssu-Yi Chen.

## Installation

You can install directly from GitHub:
```bash
pip install git+https://github.com/SSUYICHEN/Adiabatic-Quantum-Simulation.git
```

Or clone the repository:
```bash
git clone https://github.com/SSUYICHEN/Adiabatic-Quantum-Simulation.git
cd DMET
pip install .
```
